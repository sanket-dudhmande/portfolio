Backend Application

Task Management REST API

A backend application built using Spring Boot for managing tasks, priorities, and status tracking through structured REST APIs.

View GitHub Live Demo

Project Overview

This project was built to understand backend application design using Spring Boot and REST APIs. The focus was on creating structured APIs, organizing application layers properly, and handling persistent storage using MySQL.

Key Features

CRUD Operations

Create, update, delete, and manage tasks efficiently.

Validation

Implemented request validation and basic error handling.

Layered Architecture

Separated controller, service, and repository logic.

Docker Support

Containerized application for consistent deployment.

Challenges & Learning

One of the main challenges was structuring the application in a clean and modular way instead of writing everything in a single class. This helped improve understanding of backend architecture, request flow, and maintainable code organization.
